# Kubernetes 学习路线图（基于《Kubernetes in Action》全书 18 章）

> 说明：本文是总纲。细节按模块拆在 `01`~`08` 文件里。页码指 PDF 页码（`assets/text/k8s-in-action.txt` 里的 `=== PAGE n ===`）。
> 学习节奏建议：**每天 1 个主题，每周 1 个模块，共 7 周**。学完每节先做题，再往下。

## 一条主线（先记住这张地图）

全书讲的就是一条故事线，按顺序是：

```
为什么需要 K8s  →  怎么打包(容器/镜像)  →  怎么跑起来(Pod)
→  怎么保证活着和够数(探针/副本)  →  怎么被访问(Service)
→  怎么存数据(卷/PV)  →  怎么配(ConfigMap/Secret)
→  怎么升级(Deployment)  →  怎么跑有状态(StatefulSet)
→  内部怎么转(机制)  →  怎么守(安全)  →  怎么省(资源)
→  怎么自动(伸缩)  →  怎么摆(调度)  →  怎么写好(最佳实践)
→  怎么扩(扩展)
```

## 学习方法（照做）

1. **先动手再理论**：每个模块先跑一遍实践，带着现象去读"为什么"。
2. **每天 30 分钟做题**：每个模块文件末尾有自测题，答完对照正文回查。
3. **笔记四段式**：概念 / 命令 / 易错点 / 我的疑问，写进 `notes/weekN/dayN.md`。
4. **遇到问题用检索流程**：`grep -n "关键词" assets/text/k8s-in-action.index.md` 定位 → 只读正文命中处前后 30 行。

## 版本提醒（重要）

本书基于 **Kubernetes 1.6~1.9** 时代，部分内容已过时，学习时注意：

| 书里 | 现状 |
|---|---|
| Heapster 做监控聚合 | 已被 **metrics-server** 取代 |
| `kubectl run` 创建 RC | 现在默认创建 **Deployment** |
| `kubectl rolling-update` | 早已移除，用 Deployment |
| PodSecurityPolicy(PSP) | **1.25 已移除**，用 Pod Security Admission |
| `extensions/v1beta1` 等旧 API | 已迁移到 `apps/v1` 等稳定版本 |
| rkt | 已停止维护 |
| Tiller(Helm v2 服务端) | Helm v3 已去掉 Tiller |

> 学"原理和概念"看这本书没问题；学"具体 YAML 字段和版本"以当前官方文档为准。
