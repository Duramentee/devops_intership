# Linux 故障索引（现象 → 机制 → 命令）

> **为什么需要这个文件**
> `labs/实践任务.md` 是按「任务 / 命令」组织的**字典**；而真实排障和面试是按「**现象**」提问的。
> 隔几天就忘，不是没记住，而是缺一条「从现象出发」的检索路径。
>
> **用法**：① 遇到现象先查第一张表；② 每解决一个新问题，自己在表里回填一行；③ 每周用「现象」提问抽背，而不是用命令提问。
>
> 下表「出处」列里的 `实践任务.md` 指 `labs/实践任务.md`。

## 1. 现象索引表（主表）

| 现象 | 先想哪个机制 | 第一条命令 | 出处 |
|---|---|---|---|
| 删了原文件，另一个名字还能读内容 / 软链接打不开 | inode + 目录项（链接计数） | `ls -li`、`stat 文件` | `实践任务.md:456-511` |
| `df -h` 说满了，`du` 加起来却没那么多 | ① 进程持着**已删除文件**的 fd ② 挂载点覆盖 ③ `du -sh /*` 不含 `.` 开头目录、无权限目录被跳过 | `lsof +L1` | `实践任务.md:116`、`140`、`143` |
| 文件名带空格/换行时循环出错、变量被拆开 | Shell **分词**（IFS）+ 通配符展开 | `for f in "$dir"/*; do [ -e "$f" ] \|\| continue; ...` ；`rm "$file"` | `实践任务.md:1664-1686` |
| `awk ... \| uniq -c` 统计结果不对 | `uniq` 只合并**相邻**行 | 先 `sort`，或直接用 awk 关联数组 | `实践任务.md:982-985` |
| `ps` 里出现 `Z` / `defunct` | 子进程已退出，父进程没 `wait()` 回收 | `ps -eo pid,ppid,stat,cmd`；`ps aux \| awk '$8=="Z"'` | `实践任务.md:1231-1242` |
| 服务停了没善后 / 数据不一致 / 裸 `kill -9` 出事 | 信号语义：SIGTERM 可捕获，SIGKILL 不可 | `kill PID` → 等 2~3s → `kill -9 PID` | `实践任务.md:1164-1180`、`1248` |
| 关掉终端后服务没了 | SIGHUP 与终端绑定 | `nohup cmd > log 2>&1 &` + `echo $!`；长期用 systemd | `实践任务.md:1186-1201` |
| `find` 找不到 / 删不掉文件 | find **不展开**路径里的通配符；`-name` 匹配 basename；`-delete` 隐含 `-depth` | `find /data -type f -name '*.tar.gz' -mtime +30 -print`（先预览） | `实践任务.md` 第七部分 |
| 端口被占用 / 服务连不上 | socket 状态与进程关系 | `ss -tlnp`、`lsof -i :8080` | `实践任务.md:1276-1320` |
| `TIME_WAIT` 堆积 | TCP 四次挥手 + 2MSL 等待 | `ss -tan state time-wait \| wc -l` | `实践任务.md:1428` |
| load 很高但 CPU 不忙 | load 含 **D 状态**（不可中断 I/O 等待） | `top` / `iostat` | `实践任务.md:75` |
| 容器里"磁盘满"但宿主机不满 | 同 fd 与挂载命名空间机制 | `df -h` / `lsof +L1`（容器内也要查） | 预留：学 K8s 时回填 |

## 2. 六个必背机制（出场率最高，能串起上面所有现象）

| # | 机制 | 一句话 | 能解释的现象 |
|---|---|---|---|
| 1 | **inode 与目录项** | 文件名只是目录里一条「名字 → inode」记录；数据/权限/时间戳都在 inode 上 | 硬链接 vs 软链接、`rm` 只减链接计数、`df -i` 耗尽 |
| 2 | **fd 与内核打开文件表** | 进程通过 fd 引用 inode；`rm` 只删目录项，fd 还在空间就不还 | 磁盘"删了还不释放"、`lsof`、**重启进程才释放空间**、socket 也是 fd |
| 3 | **Shell 展开顺序** | 别名 → 花括号 → 变量/命令替换 → **分词(IFS)** → 通配符 → 去引号，**全部在命令执行前** | 引号坑、`$(ls)` 坑、glob 坑、`rm $f` 坑 |
| 4 | **进程生命周期** | `fork` → `exec` → 退出后**等父进程 `wait()`** 才回收；父进程先死则被 init 收养 | 僵尸（Z）、孤儿（PPID=1）、容器必须有 init 进程 |
| 5 | **信号语义** | 15 可捕获（优雅退出），9 不可；HUP 源于终端断开 | 优雅停止、`nohup`、**K8s 删 Pod 先发 SIGTERM 再 SIGKILL** |
| 6 | **管道与流的时机** | 每个进程独立、管道是内核缓冲；命令按行/记录流式处理 | `uniq` 必须先 `sort`、awk 一次遍历聚合比"循环"高效、`grep \| grep` 的代价 |

## 3. 复述法：让"隔四五天"还记得

| 动作 | 做法 | 判断标准 |
|---|---|---|
| **先做后看** | 看答案之前，自己先写一版（哪怕错） | 一读就懂 ≠ 学会；**自己错过一次才记得住** |
| **三句复述** | 合上笔记，用「现象 → 机制 → 命令」讲出来 | 讲不出机制那一步 = 还在背 |
| **现象提问** | 抽背时问"删了文件空间不释放怎么办"，**不要**问"`lsof +L1` 是什么" | 面试也是按现象问的 |
| **回填索引** | 每解决一个新问题，往本表加一行 | 表变长 = 真在积累 |
| **间隔复习** | 第 1 天 / 第 3 天 / 第 7 天各抽一次，每次 5 分钟 | 抽背比重读有效得多 |
