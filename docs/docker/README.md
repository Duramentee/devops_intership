# Docker 词典 · 总入口

> **它解决什么问题**：写 Dockerfile、跑容器、排障时，你脑子里的顺序是「**现象 → 机制 → 命令**」，而不是「命令 → 猜用途」。
> 这份词典按这个顺序组织，**不是教程**，是**随时可查的手册**。
> 配合：`docs/k8s_in_action/01-容器与K8s入门.md`（概念提炼）、`docs/linux/Linux-故障索引.md`（Linux 侧现象）、`plan/week1/任务明细.md`（每天练什么）。

## 一分钟速记版（先背这 6 条，其余随用随查）

| # | 结论 | 展开在 |
|---|---|---|
| 1 | 容器 = **namespace（隔离视图）+ cgroup（限制资源）** 的普通 Linux 进程，与宿主**共用内核** | `02` |
| 2 | 镜像 = **一堆只读层**；容器启动时在最上面加一个**可写层** | `02` |
| 3 | **Dockerfile 每条指令 = 一层**；改动层之后的层全部重建（缓存按层命中） | `04` |
| 4 | **跑**镜像得到**容器**；容器删掉，可写层里的数据就没了（要留数据用 volume） | `02`/`03` |
| 5 | **构建时的事用 `RUN`，运行时的事用 `CMD`/`ENTRYPOINT`** | `04` |
| 6 | 排障顺序：**在不在 → 为什么退 → 日志 → 环境 → 资源** | `05` |
