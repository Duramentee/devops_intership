### 5. GitHub Actions 概念学习（需完成口头自测）

| 概念 | 用自己的话说明 | 自测问题 |
|---|---|---|
| 事件（Event） | GitHub 上发生的事情，可作为自动化流程的触发条件，例如提交代码或创建拉取请求。 | 哪些事件应触发代码检查？ |
| 工作流（Workflow） | 仓库中版本化保存的一份自动化流程定义，通常放在 `.github/workflows/`。 | 工作流文件定义了什么？ |
| 作业（Job） | 工作流中的执行单元；不同作业可以并行运行，也可以通过依赖关系安排先后。 | 哪些检查适合分成不同作业？ |
| 执行器（Runner） | 实际运行作业步骤的计算环境。 | 作业定义与执行器分别负责什么？ |
| 步骤（Step） | 一个作业内按顺序执行的命令或可复用动作。 | 步骤之间如何组织执行顺序？ |
| 动作（Action） | 可复用的自动化单元，可作为步骤使用；它不是整个工作流。 | 动作与步骤、工作流有什么区别？ |
