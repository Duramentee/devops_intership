- 先完成笔记中的两条命令，再用一个自己创建的临时目录验证匹配范围。

- 第一次只打印路径；检查结果确实只包含目标测试文件后，才可在临时目录内演示删除。
- 不要将题目中的 `/data` 当成可直接删除的练习目录；不要使用未经检查的 `-delete`。
