## 练习素材的准备

三剑客的练习需要一份**自己构造**的样本文件，不要依赖真实日志（真实日志里既包含隐私信息，字段格式也无法覆盖边界情况）。样本至少覆盖下面四类情况：

| 覆盖项 | 目的 |
|---|---|
| 多个字段、以固定字符分隔（例如空格或冒号） | 用于 `awk -F` 取字段与 `cut -d` 对照 |
| 时间字段位于行的固定位置 | 用于按小时聚合的统计 |
| 同一个取值重复出现，且不保证相邻 | 用于验证 `uniq -c` 只比较相邻行，必须先 `sort` |
| 少量不符合格式的行 | 用于验证筛选条件写得过宽或过窄时的结果 |

把构造样本的命令写进 `sh/` 目录的同一个文件里，保证样本可以重建。
