# code/ · 每日代码目录

**约定：每天一个代码目录，和笔记一一对应。**

| 代码目录 | 对应笔记 | 内容 |
|---|---|---|
| `code/weekN/dayN/` | `notes/weekN/dayN.md` | 当天的源码 / Dockerfile / K8s YAML / 脚本 |

规则：

1. 当天所有**可执行产物**都放这里，不要散落在仓库根目录。
2. 每天结束 **commit 一次**（commit 历史 = 学习证据，也是简历素材）。
3. 每个目录里可以放个 `README.md` 写「今天放了什么、怎么跑」。
4. 老师实训作业的脚本归 `labs/`，不要混进来。
