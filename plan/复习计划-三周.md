# 三周复习计划 · Linux / Shell / Docker / Kubernetes

> 编制日期：2026-10-12。周期：2026-10-12 至 2026-11-01（21 天，与 `plan/三周冲刺计划.md` 同一周期）。
> 编制原因：`plan/三周冲刺计划.md` 只规定了第 3 周为「面试复习」，但三个星期要覆盖的是四个域（Linux 基础与命令、Shell 编程、Docker、Kubernetes）的完整一遍，跨域且跨度长，必须先有排程，否则会出现「临近面试才发现某一域完全没复习」。
> 与主线的分工：上午 3 小时左右留给 `plan/三周冲刺计划.md` 的新内容主线；下午与晚上 3 至 4 小时用于本复习计划。第 3 周与该计划的第 3 周（面试复习与投递）合并。主线（CI → 可观测性 → 面试与投递）不因本计划调整。
> 排程方式（2026-10-12 修订）：四个域**每天都要出现**，因为交错进行比按域分块更能减慢遗忘；同时每天保留一个**主域**做深度推进，否则每个域只能浅过。

## 2. 每天的结构与复习方法

### 2.1 每个知识点见三次（三遍法）

> 依据：`docs/linux/Linux-故障索引.md` §3「间隔复习：第 1 天 / 第 3 天 / 第 7 天各抽一次」。三遍法把「见一次」拆成三种不同动作，避免三遍做同一件事。
> 适用条件：**长期未接触导致检索失败时，第一遍必须允许开卷。** 对已经衰减的知识点直接做「遮结论口述」，得到的是空白而不是诊断 —— 空白既不能定位缺口是机制还是命令，也不提供重建的线索。

| 遍次 | 动作 | 允许开卷 | 判据 |
|---|---|---|---|
| 第一遍 · 重建 | 先讲机制（定义 + 机制 + 本工程用例），再做一个最小复现实验；命令从 `docs/`、`labs/` 或 `man` 里查 | 允许 | 能说出「谁在做、按什么规则做」，并能用命令复现该现象 |
| 第二遍 · 巩固 | 第 3 天：只用「现象 → 机制 → 命令」三段复述，答不出的当场查 | 中途允许 | 三段齐全 |
| 第三遍 · 检索 | 第 7 天：遮住结论列口述，全程不开卷 | 不允许 | 机制与判定条件都说得出 |

> 队列 L1~S4 描述的是**第一遍**的内容；`notes/错题本.md` 的遮结论复查属于**第三遍**的动作。同一知识点按 1 / 3 / 7 天间隔排三遍。
> 起步期说明：10-12 至 10-14 三天处于重建期，每日第 3 段的错题抽背改为「允许查一次再答」；10-15 起恢复不开卷。

### 2.2 每天的五段结构

> 设计依据（2026-10-12 修订）：四个域必须在同一天内全部出现，遗忘才会变慢。因此把当天时间切成「一个主域深挖 + 三个副段覆盖其余域」。

| 段 | 时长 | 域 | 动作 | 作用 |
|---|---|---|---|---|
| 1 主域 | 75 至 90 分钟 | 按四天循环轮转：Linux → Kubernetes → Docker → Shell | 推进该域的队列（见第 3 节） | 深度推进，把该域推到底 |
| 2 | 40 分钟 | Linux | Linux 每日一题 DayN，机制复述（21 天正好一轮） | Linux 每日必触 |
| 3 | 30 分钟 | 四域 | 错题抽背：四个域各抽 1 条，遮住「正确结论」列口述，A 类优先 | 保证「每天涉及全部领域」 |
| 4 | 30 分钟 | 主域之外 | 域外口述：从 `notes/week2/提炼-反例与关系.md` 的条件句或 `docs/docker/*` 篇末自测题抽 2 题 | 防止只在主域内循环 |
| 5 | 20 分钟 | — | 回填：`notes/错题本.md` §七 + 当天复习记录 + 确认次日队列 | 闭环 |

合计 195 至 210 分钟（约 3.25 至 3.5 小时）；需要时可把第 1 段延长到 4 小时。

> 段 3 是「每天涉及全部领域」的保证；段 1 的轮转负责把每个域推进到底。若某天主域就是 Linux，则段 4 从 Kubernetes 与 Docker 的题库中抽取。

## 5. 判定标准与失效信号

| 判定项 | 通过 | 不通过（需要重做） |
|---|---|---|
| 机制复述 | 能说出「哪一层对象 / 哪一条链路 / 哪一个时刻」 | 只能说出结论，说不出限定条件 |
| 现象反推 | 只看现象列能说出「字段 → 机制 → 第一条命令」 | 需要提示才能找到字段 |
| 错题复查 | 遮住「正确结论」列能完整口述 | 说得出结论但说不出依据字段 |
| 判定依据 | 落在具体字段或具体内核机制上 | 依赖「感觉」「印象」「上次好像是」 |

> 失效信号：某一域连续两天出现「机制复述不通过」，则该域排在周末综合日单独加练，不进入下一域。
